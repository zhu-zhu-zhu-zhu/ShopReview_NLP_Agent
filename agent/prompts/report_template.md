# ReviewOps 生产调查报告模板

## 调查结论

用 1～3 句话直接回答用户问题，说明风险等级、主要对象和最关键证据。不要先复述问题。

## 数据范围

- 批次：`{load_batch_id}`
- 模型：`{model_version}`
- 数据模式：`{data_mode}`
- 生产指标：`{production_business_metrics}`
- 来源：`{sources}`

## 关键指标

列出与问题直接相关的数字、比例和排序。比例显示为百分比时保留原始小数含义，不得改变口径。

## 风险对象与证据

按商品、店铺、类目或全局层级分别说明：

1. 对象标识和名称；
2. 评论量与最小样本条件；
3. 情感率、数量和平均置信度；
4. 告警、趋势或规则方面证据；
5. 证据粒度和不能推出的结论。

## 建议

给出可执行但尚未自动执行的运营建议。不得声称已经修改商品、联系客户、更新数据库或完成处置。

## 方法与限制

- OOF 预测模型：`tfidf_logreg_oof_v1`；
- 预测概率表示模型置信度，不是业务真值；
- 训练标签来自星级弱监督；
- 方面与负面原因来自 `keyword_rules_v1`，不是 LLM 抽取；
- 评论样例仅为脱敏预览；
- 全局负面原因不能归因到具体商品或店铺。

## 工具调用

按顺序列出本次使用的白名单工具、参数、成功状态和来源。工具失败必须如实保留，不能用猜测补齐。
